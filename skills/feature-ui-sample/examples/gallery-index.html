How to mix and match

Every sample uses the same colour and font token names: --bg --surface --surface-2 --line --ink --muted --accent --accent-2 --good --warn --bad --radius --font-display --font-body --font-mono.

  1. Pick the layout you like (say #06).
  2. Pick the colours you like (say #05).
  3. Paste #05's :root block into #06. Done.

What's on each card

What the screen leads with, the design source badge, the layout frame, the chart types, the 5-colour palette and a one-line how it would work. Each sample repeats this at its bottom in a “Design DNA” strip.

These are throwaway mockups. They live only in design-samples/ and don't touch the real app. Excluded on request: neumorphism, skeuomorphism, claymorphism (see rejected.md).
